# 🪨📄✂️ Rock Paper Scissor

A simple, responsive Rock Paper Scissor game built with vanilla HTML, CSS, and JavaScript. Play against the computer and track your score in real time.

## 🎮 Play it live

👉 [Play Rock Paper Scissor](https://github.com/Swetanki/Rock-Paper-Scissor.git)

## ✨ Features

- Play Rock, Paper, or Scissor against the computer
- Real-time score tracking for both player and computer
- Instant win/lose/draw feedback with color-coded results
- Clean, responsive UI with smooth styling

## 🛠️ Built with

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks or libraries)
